# Shared page helpers

The page scripts each kept their own copies of a few helpers. They now take them from
`static/studio.js`, which every page loads before its own script. The scripts stay classic scripts
(no modules and no build step), and no page behaves differently.

- `window.studio` now also offers:
  - `el`: the editor's element builder. It now leaves out any attribute that is false, null or
    undefined, `class` and `text` included; before, those two were set to the value's text.
  - `fact`: a term and its value in a description list, from the setup page and the editor.
  - `plural` and `sleep`, which were copied in three scripts and two scripts.
  - `warnBeforeLeaving(busy)`, the "leave this page?" prompt that setup, drafting and the editor
    each wired up by hand.
- Setup and the drafting page build their elements with `el` instead of `document.createElement`.
- The editor calls `studio.…` like the other scripts, instead of `window.studio.…`.
- Visible differences: none. The editor's facts no longer carry an empty `class=""`.

`tests/e2e/test_scripts.py` checks the helpers in a browser. It also checks that every helper a
page script takes from `studio` exists there: the drafting page's script runs only on the hosted
studio, so no browser journey runs it. Leaving the editor asks first only while it has unsaved
changes. Mutation checks confirmed that removing a helper from `window.studio`, the prompt itself,
or `el`'s handling of missing values each fails a test.
